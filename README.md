# SurviveUIDemo

**Unity 3D 第一人称科幻生存游戏原型** · 个人主导 + AI 辅助实现 · 分阶段交付（Phase 01–09）

> 🎬 演示视频：45 秒功能与交互演示 —— 链接待补充 / 见投递附件

---

## 项目概览

以科幻飞船为背景的第一人称生存原型。涵盖玩家控制、舰内场景、设备交互、门禁机关、游戏 UI、手柄输入、3D 资产与镜头过场。

**开发模式**：个人主导、AI 辅助实现。本人负责需求规划、AI 开发指导、交互设计与质量验收，主要功能代码由 AI 工具辅助生成。

---

## 玩法与系统

| 模块 | 内容 |
|---|---|
| 第一人称 | 移动、视角、镜头过场 |
| 舰内探索 | 飞船内场景、门禁与机关 |
| 设备终端 | 终端聚焦与退出、界面状态切换 |
| 资源加工 | 加工流程与控制器交互 |
| 据点升级 | 据点控制器、模块拓扑展示 |
| 出发准备 | 出发前准备界面（深空终端风格） |
| 腕表 HUD | 腕表径向界面、地图、导航雷达 |
| 输入 | 手柄适配，Confirm / Back 等语义化输入动作 |

## 技术栈

- **引擎**：Unity `6000.5.7f1`
- **渲染**：Universal Render Pipeline `17.5.0`
- **输入**：Input System `1.20.0`
- **UI**：uGUI `2.5.0` + UI Toolkit
- **测试**：Unity Test Framework `1.7.0`（PlayMode）
- **3D 资产**：Blender

## 开发方式

采用**分阶段开发 + 增量验收**，每个阶段以 Git 标签封存：

```
需求定义 → AI 辅助实现 → 实际运行验证 → 问题反馈与修改 → 回归验收 → Git 阶段封存
```

- **91 次提交**，跨 10 个阶段标签：`phase-01-green` … `phase-09-green`、`phase-09a-green`
- 每个 `*-green` 标签代表该阶段功能已通过实际运行检查与回归验收
- 输入规范与 UI 语言有独立文档约束（见 `Docs/`）

## 仓库结构

```
Assets/
├── _Project/        # 项目自有代码、模型、配置
├── Scenes/          # 场景
├── Settings/        # URP 等渲染设置
├── UI Toolkit/      # UI Toolkit 资源
└── TutorialInfo/    # 引擎模板附带
Artsource/           # Blender 源文件、参考图与阶段性验证渲染
Docs/                # 输入优先级、UI 语言风格、各阶段集成与热修记录
Packages/            # 包依赖清单
ProjectSettings/     # Unity 工程设置
```

> `Library/`、`Temp/`、`Logs/`、`Build/`、`TestResults*.xml` 均已在 `.gitignore` 中排除，不纳入版本管理。

---

## 如何打开

1. 安装 **Unity 6000.5.7f1**（含 URP 模板所需模块）
2. 用 Unity Hub 打开本仓库根目录
3. 首次打开会自动重新导入资源并重建 `Library/`（耗时数分钟）
4. 打开 `Assets/Scenes` 下的主场景即可运行
